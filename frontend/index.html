The 6 Pillars of Crisis Decision Architecture

Meeting the rigorous technical standards demanded by high-stakes urban infrastructure resilience.

PILLAR 01

Honest Probabilities & The Twin Test

Maintains strictly calibrated probabilities over four mutually exclusive hypotheses: H₀ (Noise), H₁ (Sensor Failure), H₂ (Isolated Incident), H₃ (Cascading Crisis).

Brier Score: BS = 1/N ∑ (P_t - y_t)² — Divergence Penalty if H(P) < ε before t=07
  • Strict penalty for confident wrong guesses before split
  • Maximum entropy prior during uninformative prefixes
  • Asymmetrical rewards for early post-split commitment
PILLAR 02

Optimal Stopping & Cost Model

Weighs the compounding value of evacuation lead time against the crippling penalty of false alarms (city fatigue / cry-wolf effect).

J*(x) = min { C_stop(x), C_continue(x) + E[J*(x_{t+1}) | x_t] }
  • Bellman dynamic programming on partially observed Markov states
  • Cost of false ESCALATE: public panic, trust decay, \$2.5M commerce halt
  • Cost of late ESCALATE: exponential casualty curve per minute delayed
PILLAR 03

Foresight & Causal Reasoning

Forecasts the next three events with tight time horizons, proving it internalizes the causal mechanics of physical infrastructure rather than superficial correlation.

P(Event_{k} | do(Rainfall > threshold), G_causal) ∀ k ∈ {1,2,3}
  • Do-Calculus intervention reasoning distinguishes root cause from symptoms
  • Predicts hydraulic overflow → electrical trip → telemetry loss sequence
  • Validates that downstream events conform to physical flow constraints
PILLAR 04

Learning & Prior Shifts

Autonomously updates trust in unreliable data sources across episodes and adapts to silent seasonal base-rate shifts (e.g., monsoon arrival) without offline retraining.

w_i(t+1) = w_i(t) × exp(η × Accuracy_i) — Dirichlet Prior Update
  • Continuous online meta-learning with streaming decay
  • Bayesian discounting for aging or degraded hardware sensors
  • Automatic adaptation when background storm base-rates triple
PILLAR 05

Adversity & Cutout Resilience

Handles massive telemetry dropouts (e.g., camera network gateway failure) and structured malicious mimics without crashing or hallucinating false crises.

Cluster_Outage(G) = 1 ⇒ Impute_Missing(S) ~ SpatialKriging(Neighbors)
  • Identifies single-point-of-failure gateway outages masking 100 sensors
  • Neutralizes astroturfed social media panic swarms via cross-verification
  • Robust buffering for out-of-order dispatch logs and retrospective retractions
PILLAR 06

Stability & Anti-Flip-Flop

Guarantees decision stability. Strictly prevents erratic alert flip-flopping (e.g., ESCALATE → WATCH → ESCALATE) which irreversibly destroys municipal credibility.

θ_{escalate} = 0.82, θ_{de-escalate} = 0.25 (Dual-Threshold Hysteresis)
  • Schmitt-trigger hysteresis bands for action transitions
  • Monotonic public alert state machine with minimum confirmation windows
  • Strict cool-down protocols before de-escalation can be signaled
